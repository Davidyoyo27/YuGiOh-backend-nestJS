# YuGiOh Project

1. Clonar proyecto
2. ```npm install```
3. clonar el archivo ```.env.tamplate``` y renombrarlo a ```.env```
4. cambiar las variables de entorno
5. levantar la base de datos ```docker-compose up -d```
6. levantar: ```npm run start:dev```
